# 假名练习（Kana Practice）

一个无需登录的日语假名与罗马音练习网页，适合在电脑或手机上学习平假名、片假名和常用单词。

在线体验：[https://m1lkyshark.github.io/kana-practice/](https://m1lkyshark.github.io/kana-practice/)

## 主要功能

- **学习模式**：按五十音单元学习，先查看答案，再进行每题 5 秒的掌握练习。
- **自选模式**：自由选择不熟悉的假名，直接开始针对性练习。
- **挑战模式**：支持 5 分钟、10 分钟和无限时间，可选择假名、单词或混合题型。
- **智能复习**：答错的假名会提高出现概率，并可练习错误最多的 10 个薄弱假名。
- **假名表与发音**：查看平假名、片假名及对应罗马音，点击即可朗读。
- **本地成绩记录**：自动保存成绩和学习进度，不需要账号；数据独立保存在当前浏览器中。
- 内置约 1100 个不重复的日语词汇，并适配电脑和手机界面。

## 使用技术

- HTML5、CSS3 响应式布局
- 原生 JavaScript
- LocalStorage 本地数据存储
- 本地 MP3 日语发音资源
- GitHub Pages 静态网页托管

## 本地使用

下载项目后直接打开 `index.html`，或使用任意本地静态服务器运行即可。
